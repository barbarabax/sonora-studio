RunPod · Serverless

Your endpoint ID and API key belong to your account. The endpoint and storage charges go directly to RunPod.
Set up RunPod step by step
  1. Deploy a custom RunPod Serverless worker that includes ComfyUI in /comfyui, the ACE-Step 1.5 ComfyUI nodes, Python, and this repository's integrations/runpod/worker.py. A generic endpoint is not enough.
  2. Attach a persistent network volume in the same data center and mount it at /runpod-volume. Provision at least 25 GB and keep about 22 GB free for a fresh setup; the worker reserves an additional 2 GiB.
  3. Start the endpoint and send the test input {"input":{"action":"setup"}} once. The worker downloads the fixed ACE-Step files from the official Hugging Face repository, verifies their SHA-256 checksums, and keeps them on the volume for later runs.
  4. Wait for the setup job to finish successfully and return all four models. The initial download can take a while and uses a running worker; the persistent volume may incur storage charges while retained.
  5. Enter the endpoint ID and API key here, tick the readiness box, choose Verify and save RunPod, then select RunPod as the generation provider.
Review current RunPod compute and storage pricing. Sonora does not create or rent the endpoint or volume for you.

Vast.ai · Existing instance

Sonora connects through SSH to a running instance. It never creates, starts, stops, or destroys Vast resources. Add your PC's SSH public key to Vast, and run ComfyUI on port 8188. Sonora reports missing ACE-Step nodes or models, but you install the missing files on the remote instance yourself.
WELCOME TO YOUR STUDIO

From first thought to first play.

  1. Choose a music engine.

    Use ComfyUI on this PC, your RunPod serverless endpoint, or a running Vast.ai instance.

  2. Describe a feeling.

    Set a genre, instruments, rhythm and vocal style. Start with a style idea or write freely.

  3. Add lyrics or leave them out.

    Vocal songs use your lyrics. Instrumental songs ignore the lyrics field.

  4. Shape the arrangement.

    Vocal duration is estimated from lyrics, tempo and meter. Adjust the bars or choose a manual length. Instrumentals use the duration you choose.

Tracks and favorites stay in the local data folder. Archive is reversible. Heavy mode takes longer and adds musical planning; it does not write lyrics for you.
